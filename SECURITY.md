# Security Policy

## Supported Versions

Currently, security updates and bug fixes are applied only to the latest version of `wd`.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.x | :white_check_mark: |
| < 0.1.0  | :x:                |

## Reporting a Vulnerability

Please do not open public Github issues for security vulnerabilities. Instead, report security issues by:

1. Submitting a report via a GitHub Private Vulnerability Report if enabled on the repository.
2. Or contacting the maintainer directly at **lipuntripathy74@gmail.com** or via **[souravtripathy.com](https://souravtripathy.com)**.

We will attempt to acknowledge your report within 48 hours and work with you to patch the vulnerability and release an update in a timely manner. Thank you for helping keep this project secure!
